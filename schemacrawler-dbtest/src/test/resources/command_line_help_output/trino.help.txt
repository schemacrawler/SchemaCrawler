** Connect to Trino

      --database=<database>
                          Database name
      --host=<host>       Host name
      --port=<port>       Port number
      --server=<server>   --server=trino
                          Loads SchemaCrawler plug-in for Trino
      --SSL               Enable SSL
                          Optional, defaults to false
      --user=<user>       Trino user name
                          Optional
Add connection options to the `connect` command in the SchemaCrawler Shell
