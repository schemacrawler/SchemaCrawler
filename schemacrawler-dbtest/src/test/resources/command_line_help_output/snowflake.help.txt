** Connect to Snowflake

      --database=<database>
                          Snowflake database name
      --db=<db>           Specifies the default database to use once connected.
                          The specified database should be an existing database
                            for which the specified default role has privileges.
                          Optional
      --host=<host>       Snowflake account identifier (e.g. myorg-myaccount.
                            snowflakecomputing.com)
      --port=<port>       Port number
                          Optional, defaults to 443
      --role=<role>       Specifies the default access control role.
                          The specified role should be an existing role that
                            has already been assigned to the specified user.
                          Optional
      --schema=<schema>   Specifies the default schema to use for the specified
                            database once connected.
                          The specified schema should be an existing schema for
                            which the specified default role has privileges.
                          Optional
      --server=<server>   --server=snowflake
                          Loads SchemaCrawler plug-in for Snowflake
      --warehouse=<warehouse>
                          Specifies the virtual warehouse to use once connected.
                          The specified warehouse should be an existing
                            warehouse for which the specified default role has
                            privileges.
                          Optional
Add connection options to the `connect` command in the SchemaCrawler Shell
