** Connect to Microsoft Access

      --database=<database>
                          Database file
      --host=<host>       Host name
      --memory            Load database into memory
                          Optional, defaults to false
      --port=<port>       Port number
      --server=<server>   --server=access
                          Loads SchemaCrawler plug-in for Microsoft Access
      --showSchema
      --sysSchema
Add connection options to the `connect` command in the SchemaCrawler Shell
