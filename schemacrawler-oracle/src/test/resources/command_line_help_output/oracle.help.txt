** Connect to Oracle

      --database=<database> Oracle Service Name
                            You can use a query similar to the one below to
                              find it.
                            SELECT GLOBAL_NAME FROM GLOBAL_NAME
      --host=<host>         Host name
                            Optional, defaults to localhost
      --port=<port>         Port number
                            Optional, defaults to 1521
      --remarksReporting    Report REMARKS for tables and columns
                            Optional, defaults to true
      --restrictGetTables   Restrict getTables() to accessible objects
                            Optional, defaults to true
      --server=<server>     --server=oracle
                            Loads SchemaCrawler plug-in for Oracle
      --useFetchSizeWithLongColumn
                            Use fetch size hint when LONG columns are present
                            Optional, defaults to true
Add connection options to the `connect` command in the SchemaCrawler Shell
